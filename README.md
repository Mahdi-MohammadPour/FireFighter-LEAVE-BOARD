# مدیریت مرخصی فکشن — GitHub Pages

این نسخه برای GitHub Pages ساخته شده و تمام رابط کاربری با HTML/CSS/JavaScript اجرا می‌شود.

## منطق دقیق مرخصی

- سهمیه عادی هر نفر در هر ماه: **۲۱ ساعت**.
- **۳ ساعت دقیق = یک مرخصی روزانه کامل**.
- مرخصی **ساعتی بین ۱ دقیقه تا حداکثر ۲ ساعت** قابل ثبت است.
- در فرم ثبت مرخصی، زمان شروع و پایان وارد نمی‌شود؛ شروع مرخصی به‌صورت خودکار لحظه ثبت است و پایان بر اساس مدت انتخاب‌شده محاسبه می‌شود.
- مرخصی روزانه و ساعتی از یک سهمیه مشترک ۲۱ ساعته کم می‌شوند.
- مثال: اگر کسی ۱ ساعت مصرف کند، ۲۰ ساعت باقی می‌ماند؛ بنابراین در حالت عادی می‌تواند ۶ مرخصی روزانه کامل (۱۸ ساعت) + ۲ ساعت مرخصی ساعتی دیگر بگیرد.
- مرخصی اضافه سهمیه عادی را کم نمی‌کند، ولی فقط وقتی قابل ثبت است که سهمیه عادی برای همان درخواست کافی نباشد و نام لیدر تأییدکننده ثبت شود.
- سهمیه در شروع ماه جدید بر اساس رکوردهای همان ماه محاسبه می‌شود.

## حلقه مصرف

روی کارت هر عضو یک حلقه نشان داده می‌شود که به‌صورت تصویری مشخص می‌کند چه درصدی از ۲۱ ساعت ماهانه مصرف شده است.

## شمارش ثانیه‌ای مرخصی فعال

در بخش «چه کسانی مرخصی هستند؟» هر مرخصی فعال یک حلقه زنده دارد که **هر ثانیه**:

- مقدار زمان گذشته را نشان می‌دهد.
- درصد پیشرفت مرخصی را روی محیط دایره نمایش می‌دهد.
- زمان باقی‌مانده را نشان می‌دهد.
- ساعت پایان مرخصی را کنار آن نمایش می‌دهد.

## مهم: اشتراکی شدن برای همه کسانی که لینک را دارند

GitHub Pages خودش دیتابیس مشترک ندارد. اگر فقط `localStorage` استفاده شود، هر نفر داده‌های مرورگر خودش را می‌بیند.

این پروژه حالت اشتراکی را با **Supabase** آماده کرده است. در این حالت، همه کسانی که لینک GitHub Pages را دارند، همان اعضا و مرخصی‌ها را می‌بینند و تغییرات بین مرورگرها همگام می‌شود.

### راه‌اندازی Supabase

1. یک پروژه در Supabase بساز.
2. فایل `supabase.sql` همین پروژه را کامل در **SQL Editor** اجرا کن.
3. از بخش Connect پروژه، **Project URL** و **Publishable/Anon key** را بردار.
4. در `supabase-config.js` این دو مقدار را وارد کن:

```js
window.LEAVE_MANAGER_CONFIG = {
  supabaseUrl: 'https://YOUR-PROJECT.supabase.co',
  supabaseKey: 'YOUR_PUBLISHABLE_OR_ANON_KEY'
};
```

5. هر پنج فایل پروژه را در Repository گیت‌هاب قرار بده و GitHub Pages را فعال کن.

### پشتیبان‌گیری
قابلیت «خروجی پشتیبان» و «بازیابی پشتیبان» از رابط برنامه حذف شده است و اطلاعات از طریق Supabase مدیریت می‌شود.

### امنیت این مدل

این پروژه طبق خواسته فعلی به‌صورت «هرکس لینک را دارد، امکان ویرایش دارد» طراحی شده است. بنابراین داده‌های این پنل عمداً عمومی و قابل ویرایش‌اند. برای این حالت از **Publishable/Anon key** استفاده می‌شود و نباید هیچ `service_role` یا `secret key` را داخل سایت قرار بدهی.

اگر بعداً بخواهی فقط لیدرها امکان ثبت/ویرایش داشته باشند، باید احراز هویت و RLS محدودتر اضافه شود.

## حالت بدون Supabase

اگر `supabase-config.js` خالی بماند، پروژه همچنان کار می‌کند، اما داده‌ها فقط در مرورگر همان دستگاه ذخیره می‌شوند.

## فایل‌ها

- `index.html` — رابط صفحه
- `styles.css` — طراحی و حلقه‌های مصرف/تایمر
- `app.js` — منطق مرخصی، سهمیه، شمارش ثانیه‌ای و همگام‌سازی
- `supabase-config.js` — تنظیمات پروژه Supabase
- `supabase.sql` — ساخت جدول و Policyهای اشتراکی
