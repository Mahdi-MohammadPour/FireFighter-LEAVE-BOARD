# مدیریت مرخصی تیم — GitHub Pages

این پروژه یک وب‌اپ استاتیک برای مدیریت مرخصی تیم است و برای **GitHub Pages** طراحی شده است.

## امکانات

- ثبت اعضا با `نام` و `username` دلخواه
- سهمیه ماهانه هر نفر: **۷ روز** + **۲۱ ساعت**
- هر مرخصی روزانه = **۳ ساعت** و از سهمیه ۷ روزه کم می‌شود
- مرخصی ساعتی از سهمیه ۲۱ ساعته کم می‌شود
- ثبت مرخصی اضافه با تأیید لیدر، بدون کم‌کردن سهمیه عادی
- نمایش افراد **در حال مرخصی** و **مرخصی‌های آینده** با ساعت پایان
- سابقه و امکان ویرایش/حذف رکوردها
- انتخاب ماه برای مشاهده سهمیه و سابقه همان ماه
- خروجی و بازیابی فایل JSON برای پشتیبان‌گیری
- کاملاً RTL و واکنش‌گرا برای موبایل و دسکتاپ

## اجرا روی GitHub Pages

این پروژه به سرور نیاز ندارد. کافی است سه فایل زیر را در ریشه Repository قرار دهید:

- `index.html`
- `styles.css`
- `app.js`

بعد در GitHub از مسیر `Settings → Pages` گزینه انتشار از branch اصلی را فعال کنید.

## نکته مهم درباره داده‌ها

این نسخه از `localStorage` مرورگر استفاده می‌کند. یعنی اطلاعات روی **همان مرورگر و همان دستگاه** ذخیره می‌شود و بین اعضای تیم یا دستگاه‌های مختلف به‌صورت خودکار همگام نمی‌شود.

برای نسخه‌ای که همه اعضای تیم اطلاعات مشترک و زنده ببینند، باید همین رابط به یک بک‌اند ابری مثل Supabase یا Firebase متصل شود. GitHub Pages به‌تنهایی بک‌اند اجرا نمی‌کند.

## قوانین محاسبات

- سهمیه عادی روزانه: ۷ روز در ماه
- سهمیه عادی ساعتی: ۲۱ ساعت در ماه
- مرخصی روزانه: ۱ روز از سهمیه روزانه
- مرخصی ساعتی: تعداد ساعت واقعی از سهمیه ساعتی
- مرخصی اضافه: فقط با انتخاب گزینه «مرخصی اضافه با تأیید لیدر» ثبت می‌شود و سهمیه عادی را کم نمی‌کند.
